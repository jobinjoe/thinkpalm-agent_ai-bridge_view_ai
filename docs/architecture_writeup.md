# BridgeView AI - Architecture Overview

BridgeView AI is an AI-powered software engineering accelerator designed specifically for ThinkPalm engineers working on maritime products. The architecture follows a multi-agent generative pipeline pattern, orchestrating LLM calls to analyze natural language requirements and build interactive, production-ready React applications.

## High-Level Pipeline Flow

1. **Maritime Architect Agent**:
   - **Input**: Natural language Product Requirements Document (PRD) focusing on maritime operations (e.g., Vessel Monitoring, Fuel Optimization, Ballast Tank Level, Crew Watch Portal).
   - **Responsibility**: Conducts structural analysis of the input to design a logical widget hierarchy, determine layout grids, and specify necessary telemetry parameters (like engine RPM, vessel roll angle, or fuel flow rate). It also relies on contextual tools such as the **Telemetry Schema Tool** (to map marine terms to data schemas) and the **Lucide Icon Selector Tool**.
   - **Output**: JSON schema representing the layout and data requirements.

2. **React Coder Agent**:
   - **Input**: The schema generated by the Architect agent.
   - **Responsibility**: Synthesizes pixel-perfect, responsive React component trees styled with Tailwind CSS (utilizing modern glassmorphic tokens) and TypeScript.
   - **Output**: Raw, uninspected TSX component code.

3. **UX Inspector & Auditor Agent**:
   - **Input**: The raw TSX code from the Coder agent.
   - **Responsibility**: Acts as an automated quality control measure. It runs JSX verification, checks syntax structure, ensures styling compliance, and flags or auto-corrects potential errors.
   - **Output**: Final, sync-ready, inspected TSX code.

## Execution & Deployment Environments

Once the Multi-Agent Pipeline produces the finalized React component tree, the output is routed to three distinct architectural modules:

- **Component Tree Visualizer**: Renders a dynamic, real-time node graph of the generated React hierarchy, detailing the props lists and state management hooks to give developers an at-a-glance structural understanding.
- **Interactive In-Browser Live Preview (React-Live)**: Synthesized TSX is dynamically evaluated via `react-live`, rendering the application entirely inside the client's browser (offline and instantaneously) without requiring external WebContainers or network round-trips. It relies on a **Long-Term Memory Registry** (using Browser LocalStorage) to persist layouts and parameters across sessions.
- **StackBlitz SDK Exporter**: The generated code, along with necessary Vite, Tailwind, and TypeScript configuration templates, is bundled and securely transmitted to the StackBlitz API. This creates a one-click functional web sandbox that developers can instantly launch, share, or deploy.

This streamlined, multi-agent architecture ensures ThinkPalm engineers can transition from abstract specifications to validated, deployable code in seconds rather than days.
